# Data Directory

This directory contains the datasets used for training and evaluating the allosteric site prediction model.

## Structure

```
data/
├── pdb/                    # Protein Data Bank structures
│   └── *.pdb               # Individual PDB files
├── asbench/                # ASBench dataset
│   └── ASBench_Core_Set.xls  # Allosteric site annotations
└── processed/              # Processed data (generated by pipeline)
    ├── graphs/             # PyTorch Geometric graph objects
    ├── features/           # Computed features (SASA, depth, etc.)
    └── splits/             # Train/val/test splits
```

## Data Sources

### 1. ASBench Core Set

**Download**: http://mdl.shsmu.edu.cn/ASBench/

The ASBench Core Set contains 320 proteins with experimentally validated allosteric sites.

**Required file**: `ASBench_Core_Set.xls`

**Save to**: `data/asbench/ASBench_Core_Set.xls`

### 2. PDB Structures

**Download options**:

1. **Automated download** (recommended):
   ```python
   from Bio.PDB import PDBList
   pdbl = PDBList()
   pdbl.download_pdb_files(pdb_codes, pdir='data/pdb', file_format='pdb')
   ```

2. **Manual download**: https://www.rcsb.org/

3. **Bulk download**: https://www.rcsb.org/downloads

**Save to**: `data/pdb/*.pdb`

## Dataset Statistics (Expected)

- **Number of proteins**: 320
- **Total residues**: ~100,000
- **Allosteric residues**: ~2,000-5,000 (2-5% of total)
- **Average protein size**: ~300 residues
- **Resolution range**: 1.5-3.0 Å

## Data Processing

The raw data will be processed through the following pipeline:

1. **PDB Parsing** (`src/preprocessing.py`):
   - Extract atom coordinates
   - Identify residues and chains
   - Compute structural features

2. **Label Mapping**:
   - Match ASBench annotations to PDB residues
   - Generate positive labels (allosteric sites)
   - Generate negative labels (stratified sampling)

3. **Graph Construction** (`src/graph_builder.py`):
   - Build KNN graphs
   - Compute node and edge features
   - Save as PyTorch Geometric Data objects

4. **Data Splitting**:
   - Train/validation/test splits by protein
   - Ensure no sequence homology between splits

## Storage Requirements

- Raw PDB files: ~500 MB (320 proteins)
- ASBench dataset: < 1 MB
- Processed graphs: ~2-5 GB (depends on graph density)
- Features cache: ~500 MB

**Total**: ~3-6 GB

- Download datasets locally

- Share processed data via external storage if needed

## Troubleshooting

### PDB file not found
- Check PDB ID is correct in ASBench
- Some older PDB entries may be obsolete
- Use PDB's API to find updated entries

### Annotation mismatch
- PDB residue numbering may differ from ASBench
- Check for insertion codes (e.g., 100A, 100B)
- Verify chain IDs match

### Missing residues in structure
- X-ray structures may have missing loops
- Flag these proteins for exclusion or special handling
- Check resolution and B-factors

## Data Updates

ASBench and PDB are periodically updated. To refresh:

```bash
# Re-download latest ASBench
# Re-download PDB files for updated structures
python src/preprocessing.py --force-refresh
```
